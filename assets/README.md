# Assets do projeto

## Login

- `images/login/illustration.png` e `images/login/discord.png`: assets do projeto educacional [GamePlay / NLW 06, Rocketseat](https://github.com/rocketseat-education/nlw-06-react-native/tree/master/src/assets), correspondentes à referência visual em `referencias/tela-01-login.png`.
- `fonts/Rajdhani-Bold.ttf`: [Rajdhani no Google Fonts](https://github.com/google/fonts/tree/main/ofl/rajdhani), usada no título. Licença em `fonts/Rajdhani-OFL.txt`.
- `fonts/Inter.ttf`: [Inter no Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter), usada nos textos e no botão. Licença em `fonts/Inter-OFL.txt`.

Os arquivos são locais: a tela não depende de baixar imagens ou fontes durante o uso. Nenhuma biblioteca foi adicionada para utilizá-los.

## Home

Todos os arquivos abaixo ficam em `images/home/` e são carregados localmente:

| Arquivos | Origem |
| --- | --- |
| `ranked.svg`, `duel.svg`, `fun.svg`, `training.svg`, `calendar.svg`, `player.svg` | [GamePlay / NLW 06, Rocketseat](https://github.com/rocketseat-education/nlw-06-react-native/tree/master/src/assets) |
| `league-of-legends.png`, `counter-strike.png`, `apex-legends.png`, `world-of-warcraft.png` | [NLW eSports, Rocketseat](https://github.com/rocketseat-education/nlw-esports-ignite/tree/main/mobile/src/assets/games), respectivamente `game-1.png`, `game-3.png`, `game-4.png` e `game-6.png` |
| `avatar.png` | [Avatar público de Tiago Luchtenberg no GitHub](https://github.com/tiagoluchtenberg.png?size=96), usado como imagem de demonstração |
| `valorant.png` | [Logo de Valorant no Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Valorant_logo_-_pink_color_version.svg), versão rasterizada fornecida pela plataforma |
| `red-dead-redemption-2.jpg` | [Capa de Red Dead Redemption II na Wikipédia](https://en.wikipedia.org/wiki/File:Red_Dead_Redemption_II.jpg) |

O avatar e algumas capas são alternativas de demonstração, diferentes dos recortes exatos da referência. Valorant usa o logo, não a arte de personagens da imagem original. A sexta partida usa World of Warcraft como dado fictício, pois seu conteúdo não aparece na captura da Home. Essas imagens não representam dados de uma conta Discord real.

Os arquivos SVG são imagens exibidas pelo `expo-image` já instalado; não foi adicionado transformador SVG nem biblioteca de ícones. Fontes e imagens do Login foram preservadas. A autoria das marcas e artes dos jogos pertence aos seus respectivos titulares; este registro de origem não altera suas licenças.
